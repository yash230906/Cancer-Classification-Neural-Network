# Cancer Classification and Prediction Using Neural Networks

## Project Overview
This project uses a neural network to classify breast tumour samples as **Benign** or **Malignant** using the Breast Cancer Wisconsin Diagnostic dataset.

## Objectives
- Understand and explore the dataset.
- Preprocess data for machine learning.
- Build and train a neural network.
- Evaluate the model's performance.
- Visualise training accuracy, training loss, and the confusion matrix.

## Technologies Used
- Python
- NumPy and Pandas
- Matplotlib
- Scikit-learn
- TensorFlow / Keras
- Google Colab / Jupyter Notebook

## Dataset
The project uses the Breast Cancer Wisconsin Diagnostic dataset available through Scikit-learn.

- Total samples: 569
- Features: 30
- Training samples: 455
- Test samples: 114
- Missing values: 0

## Model
A neural network with dense layers is trained for binary classification.

## Results
- Test accuracy: **96.49%**
- Precision: 0.9857
- Recall: 0.9583
- F1-score: 0.9718
